Hospital Appointment Booking System

A web-based Hospital Appointment Booking System developed independently using ASP.NET Core MVC and C#.

The system helps patients book appointments with doctors and provides functionality for managing hospital-related information.

Features

- Patient management
- Doctor management
- Appointment booking and management
- User authentication and authorization
- Create, Read, Update, and Delete (CRUD) operations
- Database integration
- Organized application structure using the Repository Pattern

Technologies Used

- C#
- ASP.NET Core MVC
- Entity Framework Core
- SQL Database
- HTML
- CSS
- Bootstrap

Project Structure

The project follows an organized MVC architecture, separating application logic, data models, views, and repositories.

Installation and Setup

1. Clone the repository:
   
   "git clone https://github.com/mo2004-g/Hospital.git"

2. Open the solution in Visual Studio.

3. Configure your database connection string in "appsettings.json".

4. Apply Entity Framework Core migrations if needed:
   
   "Update-Database"

5. Run the application.
